# ISC2 CISSP — Study and Reference Notes

A reference library for the [ISC2 Certified Information Systems Security Professional (CISSP)](https://www.isc2.org/certifications/cissp) body of knowledge, organized by the eight exam domains. I hold the CISSP and maintain these notes for review, CPE refreshers, and helping others prepare.

## Exam at a glance

|---|---|
| Exam outline | Effective April 15, 2024 |
| Format | Computerized adaptive testing (CAT), English |

| Passing score | 700 out of 1000 |

## The CISSP mindset

- Think like a **manager and advisor**, not a technician.
- **Human life and safety** always come first.
- Align security with **business goals**; senior management owns risk.
- Prefer the answer that addresses the **root cause** or the broadest scope.
